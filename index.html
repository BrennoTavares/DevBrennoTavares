Projetos de Impacto Real

Sistema de Controle de Chão de Fábrica (MES)

Solução focada em operabilidade fabril para validação em tempo real das respostas dos operadores, prevenindo erros no fluxo produtivo. Automatiza o rastreio da linha de produção desde a separação de insumos até a liberação do Produto Acabado (PA).

PHP MySQL / SQL Server JavaScript Validação em Tempo Real Gestão Industrial

Sistema de Gestão de Laboratório e Qualidade (LIMS)

Plataforma para preenchimento dinâmico de fichas de análise de acordo com as especificações técnicas de cada produto. Executa a emissão automatizada de laudos de qualidade para Matéria-Prima (MP), Embalagem (EX) e Produto Acabado (PA).

PHP SQL Server Emissão de Laudos Controle de Qualidade

Plataforma de Vendas Integrada ao ERP TOTVS Protheus

Sistema comercial projetado para sincronização de pedidos, estoque e regras de negócio diretamente com o ERP TOTVS Protheus via banco de dados SQL Server e APIs, garantindo consistência financeira e agilidade nas rotinas de faturamento.

PHP SQL Server Integração ERP TOTVS Protheus

Sistema IoT de Telemetria e Monitoramento Térmico

Aplicação conectada a sensores para captação e envio contínuo de dados de temperatura e umidade para o banco de dados. Conta com algoritmo de checagem para disparar alertas quando os níveis saem do parâmetro ideal e gerador de relatórios gerenciais.
